# Enemy specialist prompt blocks

Append these to section 5 of the original art prompt pack. Use the same global unit style block and 1536 × 1024, 2 × 2 layout: idle A, idle B, attack, hit, all facing right at a consistent scale. Prefer genuine alpha transparency. A flat charcoal #2B2B2B matte is also supported by the importer. Keep every limb, weapon and wing inside its cell; no floor, text or environment. Actual attack effects are drawn by the game.

## File checklist

spitter, burrower, broodmaw, skyray, valkyr, aegisdrone, siegecrawler, shade, rigger, harpoon, breaker, gale, cantor, seraphlancer, monolith, echo. Cantor already has a painted row in `enemy-legions.png`; the standalone file below is an optional replacement, not a second machine.
